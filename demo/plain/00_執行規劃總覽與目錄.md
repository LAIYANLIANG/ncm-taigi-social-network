## 三、執行節奏建議

1. **先審閱規劃**：依序確認 `01`（資料源）$\to$ `02`（演算法）$\to$ `03`（雙重驗證）$\to$ `04`（限制與 Pre-mortem）$\to$ `05`（驗收門檻）。
2. **一鍵跑通 Demo**：執行 `demo/src/run_demo_pipeline.py`，驗證整個資料清洗、去識別化、取樣飽和監控、HITS／`BridgeHub`／PageRank／Betweenness 計算、雙語擴散模擬與時間切片轉換均無依賴錯誤且通過 G1–G5。
3. **替換真實採集資料**：確認實證管道無誤後，僅需將真實抓取的 YouTube API / PTT / Reddit / Web 超連結資料寫入與 `interactions_raw.csv` 相同 Schema 的資料表，即可直接沿用同一套演算法與驗收管線產出正式期末數據。
